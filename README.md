# GitHub Copilot CLI Demo

A simple retro-themed static webpage used to demonstrate GitHub Copilot CLI capabilities.

## Preview

The page features:

- 🖥️ CRT terminal aesthetic with scanline overlay
- 💚 Green phosphor text with glow effects
- ⌨️ Pixel font (Press Start 2P)
- ✨ JavaScript fade-in animation
- ▮ Blinking cursor

## Getting Started

Open `index.html` in any modern browser — no build step or server required.
